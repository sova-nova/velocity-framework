Welcome to velocity

One thing before you start: where should velocity keep its files? Pick your notes folder (an Obsidian vault works well), or any folder. velocity only writes inside a Tutor folder there, and never changes your own notes.

No Obsidian vault found. velocity works with any folder, but Obsidian (free) is strongly recommended: with it you can write your own thoughts into your session logs for the tutor to answer, and keep notes it can read. You can install it later and open this same folder in it.
