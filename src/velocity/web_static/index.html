Sessions

End session
Wrap up properly: the tutor catches up your progress, asks one last question, writes a recap, and closes the log. Do this when you're done for the day.
Pause
Stop for now without a wrap-up. The session stays unfinished and can be resumed. A chat with no messages for 30 minutes is paused automatically.
Resume
Carry on with a paused session, in the same log.
Continue
Start a new session that picks up from a finished one. The tutor reads the earlier session first; the new learning goes into a new log, linked to the old one.

Only one session per subject can be open at a time.
