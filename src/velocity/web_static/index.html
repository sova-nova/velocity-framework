Start a session

What you share in a session, including any notes the tutor reads, is sent to Anthropic's API (a third party).

To resume or continue an earlier session, use its button in History.

Sessions

End session
Wrap up properly: the tutor catches up your progress, asks one last question, writes a recap, and closes the log. Do this when you're done for the day.
Pause
Stop for now without a wrap-up. The session stays unfinished and can be resumed. A chat with no messages for 30 minutes is paused automatically.
Stop
Appears while the tutor is replying. It ends the reply where it is; what the tutor said so far stays in the chat and the log, marked as stopped.
Resume
Carry on with a paused session, in the same log. It uses the engine and model that ran the session last unless you pick others.
Continue
Start a new session that picks up from a finished one. The tutor reads the earlier session first; the new learning goes into a new log, linked to the old one.
Engines
Claude Code runs on your Claude plan. The API engine uses your ANTHROPIC_API_KEY and is billed per token: the chat bar shows the session's estimated cost so far, and each reply shows its own.

Only one session per subject can be open at a time.

Add a source

A PDF, EPUB, Markdown or HTML file. velocity keeps a copy in its own data folder, not in your vault.

The tutor cites it as “Name §2.4”, so a short name works best.

Prepare ahead of time

Preparing reads the pages now (OCR), so that reading them later is instant. This takes a while: about 6–7 seconds per page, and your GPU is busy the whole time.

The tutor keeps working meanwhile. If it needs a page that isn't prepared yet, it waits for the batch in progress (about a minute). Looking at pages and searching never wait.

It keeps going if you close this page or stop velocity web. You can cancel any time: finished pages are kept, and starting again continues where it stopped.
